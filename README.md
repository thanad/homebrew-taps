# thanad/taps

Homebrew tap for [thanad/saml2aws](https://github.com/thanad/saml2aws).

## Install

```sh
brew install thanad/taps/saml2aws
```

The formula builds the `playwright` branch fork, which updates `playwright-go`
to v0.6100.0 so browser driver downloads no longer use the retired Microsoft CDN.

## Upgrade

```sh
brew upgrade thanad/taps/saml2aws
```

## HEAD builds

```sh
brew install --HEAD thanad/taps/saml2aws
```
